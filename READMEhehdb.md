# Академия Автостекла

Готовая одностраничная версия сайта для GitHub Pages.

## Что работает
- навигация по разделам;
- мобильное меню;
- звонок по номеру;
- построение маршрута через Яндекс Карты;
- форма заявки с открытием WhatsApp;
- адаптация под телефон, планшет и ПК;
- изображения для визуального оформления.

`index.html` можно положить в корень репозитория и включить GitHub Pages.
